# TaskYard - Full-Stack Task Manager

A full-stack task management application built using React, Node.js, Express.js and PostgreSQL.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Edit tasks
- Delete tasks
- Search tasks
- Filter tasks by All, Active and Completed
- Form validation
- Loading and error handling# 🚀 TaskYard — Smart Task Management System

TaskYard is a full-stack task management web application that helps
users organize tasks, manage priorities, track deadlines, and monitor
their progress through a clean dashboard.

## 🌐 Live Demo

- **Frontend:** https://taskyard-fronten.onrender.com
- **Backend:** https://task-manager-qszt.onrender.com

## ✨ Features

- 🔐 User authentication and login
- ➕ Create new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 🎯 Set task priorities
- 📅 Set due dates and track deadlines
- 🏷️ Organize tasks by category
- 🔍 Search and filter tasks
- 📊 Dashboard with task statistics
- 📌 Upcoming and overdue task views
- 📱 Responsive user interface
